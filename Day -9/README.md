# Flutter Demo App

This project is a basic Flutter application created using the default Flutter template. It demonstrates core Flutter concepts such as widgets, state management, user interface design, and user interaction.

## Features

* Material Design UI
* Interactive counter button
* Stateful widget implementation
* Cross-platform Flutter application

## Technologies Used

* Flutter
* Dart

## How to Run

1. Clone the repository.
2. Run `flutter pub get`.
3. Start an Android emulator or connect a device.
4. Execute `flutter run`.

## Learning Outcomes

* Understanding Flutter project structure
* Working with widgets
* Managing state using StatefulWidget
* Building and running Flutter applications
