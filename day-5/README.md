# Counter App

## Description

A simple web-based Counter Application built using HTML, CSS, and JavaScript. The app allows users to increase, decrease, and reset the counter value through interactive buttons.

## Features

* Increment counter
* Decrement counter
* Reset counter
* Responsive and user-friendly interface
* Real-time counter updates

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
